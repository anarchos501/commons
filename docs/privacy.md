# Privacy

Every major Commons object should have a privacy envelope.

Privacy can derive from account preferences, group preferences, project preferences, node constitutional constraints, plugin policies, and affected participant preferences.

The default resolver rule is: the most restrictive valid preference wins.

Support records should auto-expire, be deletable, and avoid permanent public histories of vulnerability.
Personal-only data should remain under user control whenever it does not affect shared governance, another participant, or group accountability. Users should be able to keep it device-local, encrypt it, delete it, export it, and prevent sync or federation where possible.
